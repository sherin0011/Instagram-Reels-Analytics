# Instagram Reels Analytics Dashboard

## Project Overview

This project analyzes Instagram Reels data using SQL, MySQL, and Power BI.

The main goal of this project is to understand content trends, hashtag usage, and topic distribution by answering business questions using SQL and visualizing insights in Power BI.

## Tools Used

* MySQL
* MySQL Workbench
* SQL
* Power BI

## Dataset

The dataset contains Instagram Reels information including hashtags, topic categories, and hashtag counts.

### Dataset Fields

* reel_id
* hashtags
* lemmatized_tags
* number_of_tags
* topic
* encoded_topic

## Business Questions Answered

1. Which topics have the highest number of reels?
2. What is the average number of hashtags used per topic?
3. Which topics are most popular?
4. Which topics use the highest hashtag counts?
5. How are reels distributed across categories?
